🚔 TrafficEnforce

Advanced Traffic Enforcement & AI License Plate Recognition System

Automated Violation Detection

A hybrid JavaFX & Python solution for real-time traffic monitoring, plate extraction, and fine management.

Core Logic

JavaFX Management UI

A desktop interface for administrators to manage violations, search plate records, and track payments.

AI/ML

Python Extraction

Utilizes OpenCV and Tesseract OCR for high-accuracy license plate detection and character recognition.

Financials

Razorpay Integration

Direct integration for fine payments, allowing users to settle violations securely online.

🚀 Running the Project

This is a desktop application. To run it locally, follow these steps:

  1. Clone the repository: git clone [repo_url]
  2. Setup the Python environment in the Extract_AI folder.
  3. Install Tesseract OCR on your system.
  4. Run the JavaFX application FXMini.index.

Refer to setup.md for detailed configuration.
